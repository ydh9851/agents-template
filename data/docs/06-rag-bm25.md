# BM25 关键词检索

BM25 是本框架 RAG 的第一条检索线，实现依赖 `rank_bm25` 库的 `BM25Okapi`。

## 基本原理

BM25 是 TF-IDF 的改进版本，对两个现象做了修正：

1. **词频饱和**：一个词出现 10 次并不比出现 3 次重要 3 倍，所以 TF 部分做了饱和处理；
2. **文档长度归一化**：长文档天然更容易命中关键词，需要按文档长度做惩罚。

公式的核心是 `score = IDF × (TF × (k1+1)) / (TF + k1 × (1 - b + b × len/avg_len))`，其中 k1 默认 1.5、b 默认 0.75。

## 中文分词

`rank_bm25` 只接受 token 列表，所以本项目在 `rag/embedding.py` 里实现了 `tokenize`：

- 英文：按 `[a-zA-Z0-9_]+` 切词并转小写；
- 中文：先用正则抓出连续汉字串，然后同时输出**单字**和**相邻双字**（bigram）。

双字能显著改善中文关键词匹配，例如「断点续跑」会拆成「断点 / 点续 / 续跑」，即使查询写成「续跑」也能命中。

## 索引构建

BM25 语料直接来自向量库的 `get_all()`，保证两条检索线的文档集合完全一致，不会出现「向量能搜到但 BM25 搜不到同一篇」的错位。

## 降级策略

如果环境里没装 `rank_bm25`，`_bm25_search` 会退化为「关键词命中次数排序」的朴素实现，功能仍在，只是排序质量下降。
