# 项目概述：AgentsTemplate 多 Agent 任务执行框架

AgentsTemplate 是一个通用的多 Agent 协作框架。给它一个复杂任务，框架会自动完成「拆解 → 执行 → 验收 → 汇总」的完整闭环，无需人工介入中间环节。

## 核心能力

- **任务自动拆解**：Manager 把模糊的复杂任务转成结构化子任务列表，每个子任务都带验收标准。
- **逐个执行**：Worker 按依赖顺序执行子任务，需要外部知识时自动调用混合检索 RAG。
- **质量验收**：Checker 独立判断每个子任务是否达标，不达标就打回重做，超过重试上限才标记失败。
- **断点续跑**：每一步都写入 SQLite checkpoint，进程崩了重启后能从最后一个节点继续。
- **流式输出**：通过 SSE 把每个节点的执行过程实时推给前端。

## 适用场景

技术调研、文档撰写、竞品分析、方案设计、代码改造规划等「需要拆成若干步、每步都要检查质量」的任务。

## 不适用场景

强实时交互（如客服对话）、需要精确数值计算的场景。框架的价值在于编排与质检，不在于替代专业工具。
